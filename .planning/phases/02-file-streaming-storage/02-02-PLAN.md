    type Handler struct {

    **3. ServeHTTP method (the core streaming pipeline):**
    ```go
    func (h *Handler) ServeHTTP(w http.ResponseWriter, r *http.Request)
    ```

    Implementation flow (matching Python exactly):
    1. Call `r.MultipartReader()` — NOT `r.ParseMultipartForm()` (CONTEXT.md locked decision)
    2. Iterate parts with `reader.NextPart()`, find part with form name `"file"`
    3. If no file part found → `WriteError(w, 422, CodeNoFile, "No file field in form data or field is not a file", nil)`
    4. Extract filename from part: `part.FileName()`, pass through `SanitizeFilename()`
    5. Extract content-type from part: `part.Header.Get("Content-Type")`, default `"application/octet-stream"` if empty
    6. Create temp file: `os.CreateTemp("", "ingest-*")`
    7. `defer os.Remove(tempFile.Name())` — cleanup on ALL paths
    8. Create `sha256.New()` hasher
    9. Create `io.TeeReader(part, hasher)` — reads from part, writes to hasher
    10. Read loop in 1MB (1024*1024) chunks:
        ```go
        buf := make([]byte, 1024*1024) // 1MB chunks matching Python CHUNK_SIZE
        var fileSize int64
        for {
            n, err := teeReader.Read(buf)
            if n > 0 {
                fileSize += int64(n)
                if fileSize > h.maxSize {
                    WriteError(w, 400, CodeFileTooLarge, "File size exceeds limit", map[string]any{
                        "max_size_bytes":    h.maxSize,
                        "actual_size_bytes": fileSize,
                    })
                    return
                }
                if _, writeErr := tempFile.Write(buf[:n]); writeErr != nil {
                    // ...handle
                }
            }
            if err == io.EOF {
                break
            }
            if err != nil {
                // ...handle
            }
        }
        ```
    11. Compute `sha256Hash := hex.EncodeToString(hasher.Sum(nil))`
    12. Seek temp file to beginning: `tempFile.Seek(0, io.SeekStart)`
    13. Upload to MinIO:
        ```go
        _, err := h.storage.PutObject(r.Context(), h.bucket, sha256Hash, tempFile, fileSize,
            minio.PutObjectOptions{ContentType: contentType})
        ```
    14. On MinIO error → `WriteError(w, 500, CodeStorageError, "Failed to store file: "+err.Error(), nil)`
    15. On success → return JSON response (temporary for Phase 2 — Phase 3 adds DB records):
        ```go
        w.Header().Set("Content-Type", "application/json")
        w.WriteHeader(http.StatusOK) // Phase 3 changes to 201 when DB records are added
        json.NewEncoder(w).Encode(map[string]any{
            "sha256":       sha256Hash,
            "size":         fileSize,
            "filename":     filename,
            "content_type": contentType,
        })
        ```
    16. Log with `slog.Info("file_uploaded", "sha256", sha256Hash, "size", fileSize, "filename", filename)`

    ```go
    package server

    import (
        "net/http"

        "github.com/go-chi/chi/v5"
        "github.com/go-chi/chi/v5/middleware"

        "github.com/daluoter/malscan-ingest/internal/health"
        "github.com/daluoter/malscan-ingest/internal/upload"
    )

    // maxRequestBody is the absolute HTTP-level limit (150MB).
    // Aborts before multipart parsing for clearly oversized requests (UPLOAD-04).
    const maxRequestBody int64 = 150 * 1024 * 1024

    // NewRouter creates a chi router with health check and upload routes.
    func NewRouter(checker *health.Checker, uploadHandler *upload.Handler) *chi.Mux {
        r := chi.NewRouter()
        r.Use(middleware.Recoverer)

        // Health endpoints (Phase 1)
        r.Get("/health", checker.Handle)
        r.Get("/healthz", checker.Handle)

        // Upload endpoint with MaxBytesReader (Phase 2)
        r.Post("/api/v1/files", func(w http.ResponseWriter, r *http.Request) {
            r.Body = http.MaxBytesReader(w, r.Body, maxRequestBody)
            uploadHandler.ServeHTTP(w, r)
        })

        return r
    }
    ```

    The `http.MaxBytesReader` wrapping at 150MB (UPLOAD-04) aborts requests before multipart parsing begins for clearly oversized payloads. The per-file 100MB limit (UPLOAD-03) is enforced inside the handler during streaming.
