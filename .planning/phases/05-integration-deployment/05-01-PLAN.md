  <action>
    **1. Create `nginx/nginx.conf`:**

    ```nginx
    worker_processes auto;

    events {
        worker_connections 1024;
    }

    http {
        # Match Go's MaxBytesReader limit (150MB) per D-04 agent discretion
        client_max_body_size 150m;

        # Upstream definitions
        upstream ingest_backend {
            server ingest:8080;
        }

        upstream api_backend {
            server api:8000;
        }

        server {
            listen 8000;

            # POST /api/v1/files → Go ingest service (per D-04: method + path matching)
            location = /api/v1/files {
                limit_except POST {
                    proxy_pass http://api_backend;
                }
                proxy_pass http://ingest_backend;
                proxy_set_header Host $host;
                proxy_set_header X-Real-IP $remote_addr;
                proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
                proxy_set_header X-Forwarded-Proto $scheme;
                # Disable buffering for streaming uploads
                proxy_request_buffering off;
                proxy_read_timeout 300s;
                proxy_send_timeout 300s;
            }

            # Everything else → FastAPI backend (per D-04)
            location / {
                proxy_pass http://api_backend;
                proxy_set_header Host $host;
                proxy_set_header X-Real-IP $remote_addr;
                proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
                proxy_set_header X-Forwarded-Proto $scheme;
            }
        }
    }
    ```

    **2. Update `docker-compose.yml`:**

    a. **Remove** the `ports: - "8000:8000"` mapping from the `api` service (per D-03 — proxy takes over port 8000). The api service keeps its containerPort but no host mapping.

    b. **Remove** the `ports: - "8080:8080"` mapping from the `ingest` service — both backends are now internal to the compose network, only reachable via Nginx.

    c. **Add** the `nginx` service after `ingest`:

    ```yaml
      # Nginx Reverse Proxy — routes POST /api/v1/files to Go, everything else to FastAPI
      nginx:
        image: nginx:1.25-alpine
        ports:
          - "8000:8000"
        volumes:
          - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro
        depends_on:
          - api
          - ingest
    ```

    Per D-12: Nginx service in docker-compose.yml.
    Per D-13: nginx/ directory at project root with volume-mounted config.
    Per D-14: Nginx depends on both api and ingest services.
    Per D-05: No CORS in Nginx — services handle their own CORS.

    **Important:** The `limit_except` directive in Nginx routes non-POST methods (GET, OPTIONS, etc.) on `/api/v1/files` to the FastAPI backend, while POST goes to Go ingest. This precisely implements D-04.
