  <action>
    Create `sevenz_detect.go` in package `upload` with function:
    ```go
    func Detect7zEncryption(filePath string) (bool, error)
    ```
    Implementation:
    1. Open file, read first 32 bytes (start header)
    2. Validate 7z signature: bytes 0-5 must be `{0x37, 0x7A, 0xBC, 0xAF, 0x27, 0x1C}`
    3. If not valid 7z signature → return (false, nil) — not an error, just not a 7z file
    4. Parse NextHeaderOffset (bytes 12-19, uint64 little-endian) and NextHeaderSize (bytes 20-27)
    5. Seek to position `32 + NextHeaderOffset`
    6. Read the first byte of the encoded header:
       - If byte is `0x17` (kEncodedHeader with encryption) → return (true, nil)
       - If byte is `0x01` (kHeader — unencrypted header), scan property IDs within the header for `kMethodAES` markers: look for byte sequences indicating encryption method IDs (method ID starting with `0x06, 0xF1, 0x07` for AES)
    7. If neither encryption indicator found → return (false, nil)
    8. Any read/seek error → return (false, nil) — graceful degradation, same as ZIP

    Create `rar_detect.go` in package `upload` with function:
    ```go
    func DetectRAREncryption(filePath string) (bool, error)
    ```
    Implementation:
    1. Open file, read first 8 bytes
    2. Check for RAR5 signature: `Rar!\x1a\x07\x01\x00` (8 bytes)
       - If RAR5: read headers sequentially using vint-encoded sizes
       - Look for encryption header (type 4) — its presence means archive-level encryption → return (true, nil)
       - Look for file header (type 2) with encryption flag in header flags → return (true, nil)
    3. Check for RAR4 signature: `Rar!\x1a\x07\x00` (7 bytes)
       - Skip past 7-byte signature
       - Read archive header (type 0x73): 2-byte HEAD_FLAGS at offset +3 from header start
       - If bit 0x0080 set in HEAD_FLAGS → encrypted headers → return (true, nil)
       - Read first file header (type 0x74): 2-byte FLAGS at offset +3
       - If bit 0x04 set → file is encrypted → return (true, nil)
    4. If not RAR format → return (false, nil)
    5. Any read error → return (false, nil)

    Test files: Create test fixtures programmatically in test code:
    - For 7z: construct minimal 7z binary with encrypted header marker byte at encoded header offset
    - For RAR: construct minimal RAR4/RAR5 binary with encryption flags set
    - Also test non-encrypted variants and non-archive files

    Follow the exact same patterns as zip_detect_test.go: table-driven tests with `t.TempDir()` for fixture files.
